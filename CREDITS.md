# Credits

## Art and audio
Everything is original and generated in code. No third-party asset files are used.

- Mascot "Bimble", the "Grumblenut" enemy, "Sproutling" rescues, gems, checkpoints: built from three.js primitives (`src/player/PrimitiveMascot.ts`, `src/entities/`).
- Textures: procedurally drawn to canvas at runtime (`src/world/textures.ts`).
- Sound effects: synthesised with WebAudio at runtime (`src/audio/Sfx.ts`).
- PWA icons: generated by `scripts/make-icons.mjs`.

When CC0 assets are added later (e.g. Kenney, https://kenney.nl, CC0 1.0), list each pack here with its URL and licence.
